# Звіт до лабораторної роботи №8: Автоматизація за допомогою GitHub Actions

**Виконала:** студентка групи КН-32 Рожанська Анна

## Мета роботи
Ознайомитися з принципами безперервної інтеграції (CI) та налаштувати автоматизовані робочі процеси (workflows) у репозиторії GitHub за допомогою GitHub Actions.

## Хід виконання роботи

1. **Налаштування базового Workflow:** створено конфігураційний файл `.github/workflows/python-app.yml` для запуску Python-скрипта в середовищі `ubuntu-latest`.
2. **Ручний запуск та розклад:** додано тригер `workflow_dispatch` із вхідним параметром `name` та перевірено запуск за розкладом (`schedule` / `cron`), після чого розклад вимкнено для економії хвилин.
3. **Кілька процесів та завдань:** створено другий робочий процес (`.github/workflows/second-workflow.yml`) та налаштовано паралельне виконання кількох завдань (`jobs`) в одному файлі.
4. **Умовне виконання:** використано директиву `if:` для перевірки значення вхідного параметра під час ручного запуску.
5. **Інтеграція баджа:** додано статусний бадж стану виконання workflow у файл `README.md`.
