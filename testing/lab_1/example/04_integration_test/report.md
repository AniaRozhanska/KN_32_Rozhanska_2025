# Звіт до роботи

## Тема: Інтеграційне тестування вебзастосунків (Flask, SQLite, файлова система)

## Мета роботи: Навчитися створювати інтеграційні тести для перевірки спільної роботи вебмаршрутів Flask, бізнес-логіки, бази даних SQLite та файлової системи (JSON-експорту) без використання mock-об'єктів, із застосуванням ізольованих тимчасових ресурсів (`tmp_path`).

---

### Виконання роботи

#### 1. Встановлення інструментів та базовий запуск тестів
* **Команда встановлення:** `pip install flask pytest` (у віртуальному середовищі `venv`)
* **Команда запуску:** `pytest -v`
* **Опис:** Створили та активували віртуальне середовище у директорії прикладу (`04_integration_testing`), встановили фреймворк `flask` і тестовий раннер `pytest`, після чого перевірили виконання початкового набору тестів.

#### 2. Тестування роботи з файлами (`export_tasks` та `load_tasks`)
Для ізоляції файлових операцій використали вбудовану фікстуру `tmp_path`, яка автоматично створює та видаляє тимчасову директорію після завершення кожного тесту:

* **Перевірка порожнього списку та пошкодженого JSON:**
  ```python
  def test_export_empty_list(client, tmp_path):
      export_file = tmp_path / "empty.json"
      export_tasks(export_file)
      assert json.loads(export_file.read_text(encoding="utf-8")) == []

  def test_corrupted_json_file(tmp_path):
      bad_file = tmp_path / "corrupted.json"
      bad_file.write_text("{broken json: [1, 2,", encoding="utf-8")
      with pytest.raises(json.JSONDecodeError):
          load_tasks(bad_file)
