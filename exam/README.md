* **Група:** КН-32
* **Варіант:** [Вкажіть ваш номер варіанту, наприклад: Варіант 17]

---

## Опис завдання
Реалізувати систему обліку успішності студентів та інтегрувати її в інтелектуального освітнього асистента (AI-агента) на базі **Google ADK**.

### Основні вимоги та архітектура:
1. **Об'єктно-орієнтоване програмування (ООП):**
   * Реалізація всіх 4 парадигм ООП: *Абстракція* (абстрактний клас `Person`), *Успадкування* (класи `Student` та `Teacher`), *Інкапсуляція* (захищене приватне поле оцінок `__grades`) та *Поліморфізм* (перевизначення методу `get_role()`).
2. **Функція-інструмент (Tool):**
   * Функція `calculate_grade(name, scores)`, яка використовує створені ООП-класи для розрахунку середнього, мінімального й максимального балів, а також визначає літерний рейтинг за шкалою (90+ → A, 75+ → B, 60+ → C, нижче → F).
3. **AI-агент (root_agent):**
   * Налаштування освітнього асистента через `google-adk`, який використовує інструмент автоматизації та надає розгорнуті поради щодо навчання українською мовою.

---

   ## Як був створений цей агент

   1. У файлі `exam/student/agent.py` реалізовано:
      - абстрактний клас `Person` з атрибутами `name` та `age` та абстрактним методом `get_role()`;
      - клас `Student`, який успадковує від `Person`, містить приватний список оцінок `__grades`, додає оцінки через `add_grade()`, обчислює `average()`, `min_grade()` та `max_grade()` і повертає роль через `get_role()`;
      - клас `Teacher`, який успадковує від `Person`, має предмет `subject`, реалізує `get_role()` та метод `evaluate()` для додавання оцінки студенту.

   2. В агенті створено функцію-інструмент `calculate_grade(name, scores)`, яка:
      - створює об'єкт `Student(name, age=18)`;
      - додає кожну оцінку зі списку через `student.add_grade()`;
      - обчислює `student.average()`, `student.min_grade()` та `student.max_grade()`;
      - визначає `letter_grade` за шкалою: `>= 90 → A`, `>= 75 → B`, `>= 60 → C`, інакше `F`;
      - повертає словник з полями `student`, `average`, `min`, `max`, `letter_grade`.

   3. Для запуску агента використано Google ADK та `FunctionTool(func=calculate_grade)` у конфігурації `root_agent`.

   4. Агент можна запускати як:
      - `poetry run adk run ./student "Привіт"`
      - `poetry run adk web --port 8007`

## Інструкція із запуску проєкту

### 1. Налаштування середовища
Проєкт ініціалізовано за допомогою менеджера залежностей **Poetry**. Для встановлення всіх необхідних пакетів (`google-adk`, `python-dotenv`) виконайте:
```bash
poetry install
```
